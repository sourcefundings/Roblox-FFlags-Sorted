# Roblox FFlags Sorted
**A repository that sorts and categorizes all Roblox FastFlags by their active channels.**

**How It Works:**
- This project uses public endpoints to pull channel lists and map out their FFlags:
 - [Valra's Channel API](https://apis.rovalra.com/v1/channels): Fetches the active Roblox channels.
 - [Roblox ClientSettings API](https://clientsettingscdn.roblox.com/v2/settings/application/PCDesktopClient): Fetches the specific FFlags assigned to each channel.
